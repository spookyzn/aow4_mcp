# Age of Wonders 4 魔典策略规划

## 获取魔典数据
获取数据时，第一优先使用缓存中的数据。除非用户明确指出不使用缓存数据

## 工作流程

### 步骤1：收集初始条件

要求用户提供以下信息：
- **文化 (Culture)**：如 High Culture, Dark Culture, Feudal 等
- **初始 Affinity 点数**：各属性点数分布
- **起始魔典**：开局选择的魔典
- **目标类型**：
  - 最强单体附魔单位
  - 最强召唤/转化单位
  - 特定流派协同（如毒伤流、亡灵流等）
  - 早期扩张优势
  - 后期神级单位

### 步骤2：调用 MCP 获取数据

使用 aow4 tome MCP 工具获取：
- 所有魔典列表及其解锁条件
- 各魔典包含的法术、单位、附魔
- 单位属性、技能、 tier 等级
- 附魔效果和适用单位类型
- 混合魔典（Mashup Tomes）信息

### 步骤3：路径分析

#### 3.1 验证解锁规则

在选择任何魔典之前，必须验证是否满足以下条件：

**基础规则：**
- 每个魔典有特定的 Affinity 解锁要求（如 Nature 2, Order 1）
- 玩家必须拥有足够的对应 Affinity 点数才能解锁
- 起始魔典由文化决定，提供初始 Affinity

**前置魔典规则：**
- 许多魔典需要特定前置魔典才能解锁
- 前置关系形成树状结构
- 必须按顺序解锁，不能跳过

**混合魔典（Mashup Tomes）规则：**
- 混合魔典需要 **两个不同 Affinity** 的组合
- 例如：Tome of Corruption 需要 Shadow + Nature
- 混合魔典通常提供独特的跨派系协同效果
- 规划路径时必须确保能同时满足两个 Affinity 要求

**解锁验证流程：**
1. 检查目标魔典的 **Tier 等级**
2. 验证 **已解锁魔典数量** 是否满足 Tier 要求
3. 检查目标魔典的 **Affinity 要求**
4. 验证 **当前 Affinity 点数** 是否满足 Tier + 魔典要求
5. 检查是否需要 **前置魔典**
6. 如不满足，规划获取所需 Affinity 和魔典数量的中间步骤
7. 考虑混合魔典的双重要求

**Tier V 特殊检查：**
- 确认这是本局唯一选择的 Tier V 魔典
- 评估是否值得用 Tier V 名额锁定该派系

#### 3.2 目标分析

根据目标类型执行相应分析：

**目标：最强附魔单位**
1. 扫描所有魔典的 Enchantment 法术
2. 按单位类型分类（步兵/骑兵/远程/飞行/巨兽等）
3. 识别可叠加的附魔组合
4. 计算理论最大属性加成
5. 考虑 Affinity 解锁成本和路径长度
6. **检查混合魔典**是否有独特的跨派系附魔
7. **验证 Tier**：高 Tier 附魔需要更多魔典解锁，评估时间成本

**目标：最强召唤/转化单位**
1. 扫描 Summon/Transform/Convert 类法术
2. 记录召唤单位的 tier 和属性
3. 分析召唤成本和持续回合
4. 识别早期可获得的高价值单位
5. **检查混合魔典**的特殊召唤单位

**目标：流派协同**
1. 识别触发机制（如毒伤、燃烧、冰冻）
2. 查找增强该机制的魔典和法术
3. 分析单位配合和战术优势
4. **优先考虑混合魔典**的跨派系协同

## 魔典解锁规则详解

### Tier 解锁规则

魔典按 Tier 分级，每个 Tier 有严格的解锁要求：

| Tier | 已解锁魔典数量 | Affinity 点数要求 | 特殊限制 |
|------|---------------|------------------|----------|
| I    | 无            | 无               | 起始魔典总是可用 |
| II   | ≥2 个魔典     | 无               | - |
| III  | ≥4 个魔典     | 对应 Affinity ≥3 | - |
| IV   | ≥6 个魔典     | 对应 Affinity ≥6 | - |
| V    | ≥8 个魔典     | 对应 Affinity ≥8 | 每局游戏只能解锁 **一个** Tier V 魔典 |

**重要规则：**
- 已解锁魔典数量 = 包括起始魔典在内的总数
- Affinity 点数 = 该派系的累计点数（起始 + 魔典收益）
- 混合魔典需要满足两个 Affinity 的要求
- Tier V 选择是最终决定，选择后该派系路径封顶

### Affinity 系统

- **起始 Affinity**：由文化和起始魔典决定
- **魔典 Affinity 收益**：每个魔典提供特定 Affinity +1
- **解锁门槛**：魔典有最低 Affinity 要求
- **规划原则**：通过中间魔典获取缺乏的 Affinity
- **Tier 联动**：高 Tier 魔典需要足够的魔典数量和 Affinity 双达标

### 前置关系

```
示例树结构：
Tome of Roots (起始)
└── Tome of Growth (需要 Roots)
    ├── Tome of Overgrowth (需要 Growth)
    └── Tome of Beasts (需要 Growth)
        └── Tome of Primal Might (需要 Beasts)
```

### 混合魔典（Mashup Tomes）

混合魔典位于两个派系的交界处，提供独特的跨派系能力：

**常见混合类型：**
- Nature + Order = 自然秩序/德鲁伊主题
- Nature + Shadow = 腐败/凋零主题
- Nature + Chaos = 狂野/突变主题
- Order + Shadow = 审判/镇压主题
- Order + Chaos = 平衡/冲突主题
- Shadow + Chaos = 毁灭/恐惧主题

**混合魔典策略价值：**
1. 提供单一派系无法获得的法术组合
2. 实现跨派系的单位强化
3. 创造独特的协同效应
4. 增加对手预测和反制的难度

**规划混合魔典路径：**
1. 确认目标混合魔典的双重要求（如 Nature 3 + Shadow 2）
2. 规划从起始 Affinity 到达双重要求的路径
3. 选择能提供所需 Affinity 的中间魔典
4. 评估混合魔典的性价比 vs 纯派系路线

## 分析原则

1. **严格遵守解锁规则**：每个推荐的魔典必须有明确的 Tier、Affinity 和前置验证
2. **Tier 进度规划**：提前计算到达目标 Tier 所需的魔典数量
3. **Tier V 谨慎选择**：每局只能选一个 Tier V，需评估是否值得
4. **成本效益优先**：优先考虑低 Affinity 成本的高效魔典
5. **路径长度**：尽量减少到达关键魔典的解锁步骤
6. **混合魔典评估**：主动考虑混合魔典的跨派系协同价值
7. **协同效应**：优先选择相互增强的魔典组合
8. **适应性**：考虑该路径对不同对手和地图的适应性
9. **早期强度**：评估早期游戏的生存和扩张能力
